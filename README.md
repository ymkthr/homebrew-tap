# Homebrew Tap

Personal Homebrew tap by [@ymkthr](https://github.com/ymkthr).

## Usage

```bash
brew tap ymkthr/tap
```

## Available Casks

### AgentLimits

macOS menu bar app and widgets for Codex/Claude Code usage limits and ccusage.

```bash
brew install --cask ymkthr/tap/agentlimits
```

- Homepage: https://github.com/Nihondo/AgentLimits
- Requires: macOS Sonoma or later

### oh-my-usage

macOS menu bar app showing LLM account usage limits from `omp usage`.

```bash
brew install --cask ymkthr/tap/oh-my-usage
```

- Homepage: https://github.com/ymkthr/oh-my-usage
- Requires: macOS Sonoma or later
- Not notarized: the cask removes the quarantine attribute after install so Gatekeeper does not block the first launch.
